> 일상과 같은 도시에서 어느덧 이질적인 존재가 된 주인공, 퍼즐을 해결하며 일상적인 사회에서 탈출하는 3인칭 방탈출 퍼즐 게임

---

## 2. 게임 컨셉

플레이어는 평범한 도시에서 살아가는 한 사람이다.

매일 아침이 되면 수많은 사람들이 같은 시간에 일어나 같은 방향으로 출근하고, 정해진 장소에서 같은 행동을 반복한다.

도시의 모든 사람들은 아무런 의문 없이 이러한 일상을 반복하지만, 주인공은 어느 순간부터 주변의 모습에서 이상한 점을 발견하기 시작한다.

사람들은 서로 대화하지 않고 같은 행동을 반복하며, 도시 곳곳에는 현실적으로 설명하기 어려운 이상한 현상들이 나타난다.

주인공은 도시를 탐색하면서 숨겨진 단서를 발견하고 퍼즐을 해결해 나간다.

퍼즐을 해결할수록 주인공은 자신도 알수없는 상황을 맞이한다

결국 주인공은 정해진 일상을 거부하고 자신만의 방법으로 도시를 벗어나야 한다.

### 핵심 키워드

- **Explore** : 도시와 공간 탐색
- **Observe** : NPC와 주변 환경 관찰
- **Puzzle** : 단서를 이용한 퍼즐 해결
- **Escape** : 퍼즐을 해결하고 도시에서 탈출


---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 도시를 탐색한다.
2. NPC들의 이상한 행동(대화)을 관찰한다.
3. 주변에 숨겨진 단서를 찾는다.
4. 단서를 이용해 퍼즐을 해결한다.
5. 잠겨 있는 공간을 개방한다.
6. 도시의 숨겨진 진실을 발견하고 탈출구를 찾아 도시를 빠져나간다

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
도시 탐색
 ↓
NPC 관찰,단서찾기
 ↓
이상한 점 발견
 ↓
퍼즐 해결
 ↓
새로운 공간 개방
 ↓
새로운 단서 발견
 ↓
도시의 진실 파악
 ↓
최종 탈출```

플레이어는 게임이 종료될 때까지 **탐색 → 관찰 → 단서 발견 → 퍼즐 해결 → 새로운 공간 탐색**의 과정을 반복하면서 게임을 진행한다.

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| ↑ / ← /↓/ → | 캐릭터 이동 |
| Mouse | 시점 회전 |
| Space | 점프 |
| Shift | 달리기 |
| Z | 아이템 획득 / 조사 / 문 상호작용 |

## 6. 플레이어 기능

플레이어는 3인칭 시점으로 도시와 건물 내부를 자유롭게 탐색할 수 있다.

주요 기능:
